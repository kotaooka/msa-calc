# 照合用の公開データ

`tests/published.js` が使うデータです。ファイルは NIST（米国国立標準技術研究所）の Statistical Reference Datasets（StRD）の原本のままで、各ファイルの先頭に認証値が書かれています。

- 出典：NIST, Statistical Reference Datasets — https://www.nist.gov/itl/products-and-services/statistical-reference-datasets
- NIST の資料は米国政府の著作物で、自由に使えます

| 種類 | ファイル |
|---|---|
| 一変量（平均・標準偏差） | PiDigits、Mavro、Michelso、NumAcc1〜4 |
| 分散分析（一元配置） | SiRstv、AtmWtAg、SmLs01〜09 |
| 線形回帰 | Norris |
